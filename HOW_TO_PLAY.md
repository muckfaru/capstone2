## 🟢 Beginner Tutorials - Complete Guide

### Tutorial 1: Cybersecurity Fundamentals 🔐

**What You'll Learn:** The foundation of cybersecurity - The CIA Triad and Threat Models

**Duration:** 10 minutes | **Questions:** 4 | **Max Score:** 200 points

#### What This Tutorial Teaches:

**Part 1: The CIA Triad**
Learn the three pillars of cybersecurity:

1. **🔒 Confidentiality = Keeping Secrets**
   - Only authorized people see information
   - Examples: Passwords, medical records, bank accounts
   - Protection: Encryption, passwords, access controls
   - Breach example: Hacker steals customer database

2. **✅ Integrity = Preventing Tampering**
   - Data stays accurate and unmodified
   - Examples: Bank balances, software downloads, prescriptions
   - Protection: Digital signatures, checksums, version control
   - Breach example: Hacker changes your bank balance

3. **⚡ Availability = Keeping Services Running**
   - Systems work when you need them
   - Examples: Websites online 24/7, ATMs dispense cash
   - Protection: Backup servers, DDoS protection, disaster recovery
   - Breach example: DDoS attack crashes website

**Part 2: Threat Model**
Understand the difference between threats and vulnerabilities:
- **Threat** = Potential danger (hackers, malware, disasters)
- **Vulnerability** = Weakness (outdated software, weak passwords)
- **Risk** = Threat × Vulnerability × Impact

#### The Quiz Questions:

**Q1:** A hacker steals your password database. Which CIA principle is violated?
- Answer: **Confidentiality** (data was kept secret but got exposed)

**Q2:** An attacker modifies your website to show fake information. Which is violated?
- Answer: **Integrity** (data was changed/tampered with)

**Q3:** A DDoS attack makes your website unreachable. Which is violated?
- Answer: **Availability** (service is no longer accessible)

**Q4:** What's the difference between Threat and Vulnerability?
- Answer: **Threat = potential danger, Vulnerability = weakness**

#### How to Play:
1. Read each section carefully
2. Click "Next" to move through the learning sections
3. When you reach the quiz, answer all 4 questions
4. Each correct answer = +50 points
5. Score 150+ points to get full XP!

### Tutorial 2: Network Basics 🌐

**What You'll Learn:** How computers communicate - IP addresses, ports, and protocols

**Duration:** 10 minutes | **Questions:** 3 | **Max Score:** 150 points

#### What This Tutorial Teaches:

**Part 1: IP Addresses**
Learn the "addresses" of computers:

- **Private IP (Local Network):** 192.168.x.x, 10.x.x.x
  - Only visible on your home/office WiFi
  - Example: Your laptop = 192.168.1.100
  
- **Public IP (Internet):** Assigned by your internet provider
  - Example: Your router = 45.67.89.123
  - Visible to the entire internet

**Part 2: Ports**
Think of ports as "apartment numbers" on a computer:

**Good Ports (Normal):**
- Port 80 = HTTP (websites)
- Port 443 = HTTPS (secure websites)
- Port 22 = SSH (remote login)

**Suspicious Ports (Hackers!):**
- Port 4444 = Common backdoor
- Port 31337 = "Elite" hacker port

**Part 3: Protocols**
Rules for how computers talk:
- **HTTP** = Not secure (anyone can read)
- **HTTPS** = Encrypted (safe for passwords)
- **TCP** = Reliable delivery
- **UDP** = Fast but unreliable

#### The Quiz Questions:

**Q1:** You see traffic to 45.33.32.156:4444. What does port 4444 mean?
- Answer: **Suspicious backdoor port** (not normal!)

**Q2:** What's the difference between public and private IP?
- Answer: **Public = internet, Private = local network only**

**Q3:** Which protocol is secure (encrypted)?
- Answer: **HTTPS** (the 'S' means Secure!)

#### How to Play:
1. Learn about IP addresses and ports
2. Understand normal vs suspicious connections
3. Answer 3 questions
4. Each correct = +50 points

### Tutorial 3: Encryption Basics 🔑

**What You'll Learn:** Secret codes and how encryption protects (and attacks) data

**Duration:** 12 minutes | **Interactive Challenge** | **Max Score:** 100 points

#### What This Tutorial Teaches:

**Part 1: What is Encryption?**
Turning readable text into unreadable code:
- **Plaintext:** "HELLO"
- **Encrypted:** "KHOOR"
- Need a KEY to decrypt it back

**Part 2: Caesar Cipher Demo**
Try encrypting messages yourself!
- Each letter shifts by a number (the key)
- Key = 3 means A→D, B→E, C→F
- Example: "HELLO" with key 3 = "KHOOR"

**Part 3: Decryption Challenge**
YOU decrypt a secret message!
- **Encrypted Message:** `WKLV LV VHFUHW`
- **Key:** 3
- **Your Task:** Shift each letter BACKWARDS by 3
- **Answer:** "THIS IS SECRET"

**Part 4: Why Ransomware is Scary**
Learn the difference:
- **Caesar Cipher:** Only 26 possible keys (easy to crack!)
- **Ransomware (AES-256):** 2^256 keys = impossible to crack!
  - Would take billions of years to try all keys
  - Attacker keeps the only key
  - Demands payment to decrypt your files

**Your Defense Against Ransomware:**
- ✅ Daily backups (multiple copies)
- ✅ Air-gapped backups (offline storage)
- ✅ Cloud + local copies
- ❌ NEVER pay the ransom!

#### How to Play:
1. Watch the encryption demo
2. Try encrypting messages yourself
3. Solve the decryption challenge
4. **Scoring:**
   - Correct on 1st try = 100 points
   - Each wrong attempt = -10 points
   - After 3 tries = Auto-show answer, minimum 50 points

### Tutorial 4: Malware Types 🦠

**What You'll Learn:** Identify 6 types of malware by their symptoms

**Duration:** 90 seconds (TIMED!) | **Drag & Drop Game** | **Max Score:** 100 points

#### What This Tutorial Teaches:

Learn to identify malware by reading "incident reports":

**🦠 VIRUS**
- Attaches to files (.exe, .doc)
- Spreads via USB drives, email
- Requires user to run the infected file

**🐛 WORM**
- Spreads AUTOMATICALLY across networks
- No user interaction needed
- Consumes bandwidth

**🐴 TROJAN**
- Disguises as legitimate software
- Creates backdoors for hackers
- Remote access tool

**🔒 RANSOMWARE**
- Encrypts all your files
- Demands Bitcoin payment
- Changes desktop wallpaper to ransom note

**🕵️ SPYWARE**
- Secretly monitors your activity
- Steals passwords (keyloggers)
- Runs hidden in background

**📢 ADWARE**
- Shows constant pop-up ads
- Changes browser homepage
- Tracks your browsing habits

#### How to Play:

2. **Drag the correct malware type** to each report

   Answer: 🔒 RANSOMWARE

### Tutorial 5: Phishing Lab 🎣

**What You'll Learn:** Spot fake emails and avoid scams

**Duration:** 90 seconds (TIMED!) | **Email Classification** | **Max Score:** 1200 points

#### What This Tutorial Teaches:

Learn to identify PHISHING emails by spotting red flags:

**🚩 Red Flags (PHISHING):**
- Generic greetings ("Dear Customer")
- Urgent threatening language ("Account suspended!")
- Fake domains (paypa1.tk not paypal.com)
- Suspicious links (bit.ly, weird URLs)
- Requests for passwords/credit cards
- Too-good-to-be-true offers ("You won $1,000,000!")

**✅ Legitimate Signs (SAFE):**
- Uses your real name
- Official company domain (@netflix.com, @amazon.com)
- Specific details (order numbers, dates)
- No urgent action required
- No requests for sensitive info

#### Example Emails:

**Email 1: PayPal PHISHING** 🚨
```
From: security@paypa1-secure.tk
Subject: URGENT: Verify Your Account Now!

Your PayPal account will be SUSPENDED in 24 hours!
Click here: http://paypal-verify.tk/login
```
**Red Flags:** Fake domain (.tk), typo (paypa1), urgent threat, suspicious link
**Answer:** PHISHING

**Email 2: Netflix Legitimate** ✅
```
From: noreply@netflix.com
Subject: Your Netflix receipt

Hi Sarah,
Your $15.99 payment was processed on Nov 29, 2025.
Watch history: Stranger Things S4, The Crown S6
```
**Legitimate Signs:** Real domain, uses name, specific details, no action needed
**Answer:** SAFE

#### How to Play:

1. **Read 8 emails** carefully
2. **Click SAFE or PHISHING** for each
3. **Beat the 90-second timer!**
4. **Learn from feedback** after each answer

## 🟡 Intermediate Tutorial - Complete Guide

### Tutorial 6: Hands-On Malware Removal Lab 🛠️

**What You'll Learn:** Remove malware using real Windows CMD commands

**Duration:** 15-20 minutes | **Interactive Simulation** | **Max Score:** 1000 points

⚠️ **This is hands-on practice!** You'll type REAL commands to remove malware.

#### What This Tutorial Teaches:

Experience a malware infection from start to finish, then learn to remove it!

**The Story:**
1. You download a fake game installer
2. It's actually malware (Trojan!)
3. Malware infects your computer
4. YOU use CMD commands to detect and remove it

#### Phase 1: The Download (Victim Experience)

You see: "Download Free Game - SuperGame.exe"
- You click and run it
- Trojan activates!
- **Malware installed:** `malware.exe`, `svchost32.exe`, `updater.exe`

#### Phase 2: The Infection (What Happened)

**Malware Actions:**
- ✅ Creates backdoor (port 4444)
- ✅ Connects to hacker's server (C2: 45.33.32.156)
- ✅ Adds registry key for auto-start
- ✅ Hides in AppData folder
- ✅ Creates scheduled task

**You notice:**
- Computer running slow
- Firewall alerts
- Strange network connections

#### Phase 3: DETECTION - Find the Malware

**Your Commands:**

**Command 1: `tasklist`**
See all running programs:
```
explorer.exe          Normal
svchost.exe          Normal
malware.exe          ⚠️ SUSPICIOUS!
svchost32.exe        ⚠️ FAKE svchost!
updater.exe          ⚠️ SUSPICIOUS!
```

**Command 2: `netstat -ano`**
Check network connections:
```
192.168.1.100 → 8.8.8.8:443          [Google - Normal]
192.168.1.100 → 45.33.32.156:443     ⚠️ [C2 SERVER - MALWARE!]
```

**Command 3: `dir %appdata%`**
Check AppData folder:
```
malware.exe            120 KB   ⚠️ MALICIOUS
svchost32.exe           95 KB   ⚠️ MALICIOUS
```

**✅ Completion Bonus: +100 points**

#### Phase 4: CONTAINMENT - Stop the Malware

**Your Commands:**

**Kill the processes:**
```bash
taskkill /F /IM malware.exe
taskkill /F /IM svchost32.exe
taskkill /F /IM updater.exe
```

**Block the hacker's server:**
```bash
netsh advfirewall firewall add rule name="blockmfw" dir=out remoteip=45.33.32.156 action=block
```

**Result:** ✅ Malware stopped! C2 connection blocked!

**✅ Completion Bonus: +100 points**

#### Phase 5: ERADICATION - Remove All Traces

**Your Commands:**

**Remove auto-start registry key:**
```bash
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v "WindowsUpdate" /f
```

**Delete malware files:**
```bash
del /F /Q "%appdata%\malware.exe"
del /F /Q "%appdata%\svchost32.exe"
```

**Remove scheduled task:**
```bash
schtasks /delete /tn "SystemUpdate" /f
```

**Result:** ✅ All malware traces removed! System clean!

**✅ Completion Bonus: +150 points**

#### Command Reference Sheet (Available During Game):

**Detection:**
- `tasklist` - List running processes

**Containment:**
- `taskkill /F /IM [name]` - Kill process

**Eradication:**
- `reg delete...` - Remove registry keys
- `del /F /Q [path]` - Delete files
- `schtasks /delete...` - Remove scheduled tasks

## ⚔️ Playing Code Breaker

### What is Code Breaker?
It's a **1v1 typing battle game!** You race against another player by typing code accurately. Every correct character you type **damages your opponent**. The goal is to reduce their health to zero or finish the code first!

### Step-by-Step Guide:

#### 1️⃣ Join the Lobby
- Click **"Code Breaker"** from the landing page
- You'll see the **Lobby** with a list of available rooms
- Wait a few seconds for rooms to load

#### 2️⃣ Create or Join a Room

**Option A: Create Your Own Room**
1. Click **"Create Room"** button
2. Type a room name (e.g., "My First Game")
3. Click **"Create"**
4. Wait in the room for another player to join

**Option B: Join Someone's Room**
1. Look at the list of available rooms
2. Find a room with 1 player waiting
3. Click **"Join"** next to that room
4. You'll enter the room!

#### 3️⃣ In the Room (Waiting Area)
- You'll see two player cards:
  - **Left card** = Host (room creator)
  - **Right card** = Client (person who joined)
- **If you're the Client:**
  - Click the **"READY"** button when you're ready to play
  - Wait for the host to start
- **If you're the Host:**
  - Wait for the other player to click "Ready"
  - When they're ready, click **"START MATCH"**

#### 4️⃣ Loading Screen
- Both players see a loading screen
- Progress bars show when each player is ready
- **Countdown:** 3... 2... 1... and the game starts!

#### 5️⃣ Playing the Game

**Game Screen:**
- **Top bars:** Your health (left) and opponent's health (right)
- **Center:** A code snippet you need to type
- **Timer:** 3 minutes to complete the match

**How to Play:**
1. **Type the code EXACTLY as you see it**
   - Match every letter, space, and punctuation
   - Capital letters matter! (`A` is different from `a`)
   - Don't paste - you must type!

2. **What Happens When You Type:**
   - ✅ **Correct character:**
     - You get +3 points
     - Your opponent loses 2 health
     - Green flash animation
   
   - ❌ **Wrong character:**
     - You lose -3 points
     - The current line restarts
     - Red flash animation
     - Try again from the start of that line!

3. **Watch the health bars:**
   - Your health stays at 100 (you can't hurt yourself)
   - Opponent's health drops when you type correctly
   - The bar shakes when they take damage!

**Winning the Game:**
You win if:
- ✅ Your opponent's health reaches 0
- ✅ You finish typing the entire code first
- ✅ Time runs out and you have more health (or higher score if health is tied)

**After the Game:**
- You'll see the results screen
- You can return to the room for a rematch
- Or leave and join a different game

#### 6️⃣ Leaving a Room
- Click the **"Leave"** button anytime
- You'll return to the lobby
- Can join or create a new room!

## 💡 Tips for New Players

### General Tips:
1. **Start with tutorials** - They're fun and help you level up fast!
2. **Practice typing** - Code Breaker rewards accuracy, not just speed
3. **Be patient** - Wait for the loading screens, they ensure both players are ready
4. **Have fun!** - It's okay to make mistakes, everyone is learning

### Code Breaker Tips:
1. **Read the code first** - Take 2-3 seconds to see what you're typing
2. **Type slowly and accurately** - Wrong keys restart the line and waste time
3. **Watch for spaces and capitals** - They count as characters too!
4. **Stay calm** - If you make a mistake, just restart the line and try again
5. **Keep an eye on both health bars** - Know when you're winning or need to speed up

### Typing Strategy:
- **Don't rush** - Accuracy beats speed every time
- **Breathe** - Take your time on each character
- **Learn from errors** - If you keep mistyping the same spot, slow down there
- **Focus on YOUR code** - Don't worry too much about the opponent's health

### Level Up Faster:
- ✅ Complete tutorials (earn XP)
- ✅ Win Code Breaker matches (earn XP)
- ✅ Play daily (consistent practice helps!)
